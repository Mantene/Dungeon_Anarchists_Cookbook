# The Manager Benefit

This plot thread tracks the unique arrangement where [[mordecai]] acts as the personal manager for [[princess-donut]].

## Origin
In Book 2, Chapter 1, Princess Donut chooses the **Former Child Actor** class. Embedded in this class is **The Manager Benefit**, which was selected on the secret advice of former crawler [[odette]]. 

## Rules & Limitations
- **Teleportation**: Mordecai is forced to teleport to any safe room the party enters. He has no warning when this will occur, which initially causes inconvenience (e.g., teleporting with his pants down).
- **NPC Restraints**: Mordecai is still not allowed to directly engage in combat with mobs.
- **Information Cutoff**: Mordecai loses standard guildhall access, television broadcasts, and the intergalactic information codex. He must rely entirely on his memory to guide the crawlers.
- **Lobbying and Chat**: Mordecai can now utilize the in-game chat system.
- **Alchemy Potions**: As a manager, Mordecai can physically interact with safe rooms and use alchemical tables to brew custom potions for the party. He leverages this to steal herbs from safe room kitchens and mix remedies (like the cure for Grimaldi's worm parasites and healing mixtures for Mongo).
