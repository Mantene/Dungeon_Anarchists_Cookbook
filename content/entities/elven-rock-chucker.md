# Enchanted Venomous Elven Rock Chucker

The Enchanted Venomous Elven Rock Chucker is an eight-foot-tall trebuchet contraption looted from The Dream hunters. It features a Poison Cloud enhancement and can disperse custom potions like the lawn-kill.
